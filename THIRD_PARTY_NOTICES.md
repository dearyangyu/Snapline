## Tendedero — project inspiration

The clothesline interaction was inspired by
[Tendedero](https://github.com/alejandrobujan/tendedero), by Alejandro Buján.
Snapline implements a separate Windows application with Rust, Tauri and React.
It uses its own name and original icon and is not an official Tendedero release.
