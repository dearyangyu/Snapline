# 隐私与本地数据

[返回项目首页](../README.md)

## 应用处理哪些内容

Snapline 的截图、标注、图库、贴图和角色动画在本机运行。应用没有账号系统、云上传、分析遥测或远程角色下载服务，也不会把截图发送给 AI 服务。

| 来源 | 默认行为 | 控制方式 |
| --- | --- | --- |
| 主动截图 | 启动后将虚拟桌面冻结到内存，按最终选区生成输出 | F1、界面按钮与 Esc 取消 |
| 主动导入 / 拖入 | 把支持文件复制到应用资料库 | 用户选择文件或拖放 |
| 文件夹监视 | 默认监视 Windows 截图目录、视频目录下的 Captures | 设置中增删监视目录 |
| 剪贴板自动收集 | **默认关闭** | 设置中的独立开关 |
| F3 贴图 / 主动复制 | 按用户操作读取或写入系统剪贴板 | 全局快捷键、按钮或菜单 |

截图窗口显隐选项默认关闭，因此当时可见的主界面、灵动岛等应用窗口会包含在冻结画面中。开启“截图时隐藏晾图窗口”后会临时隐藏这些窗口，结束或取消时恢复。

文件夹首次扫描只记录已有文件，之后处理新增或变化的支持文件，不自动批量导入已有内容。Windows 截图目录通过系统已知文件夹解析，可能已经被用户重定向到 OneDrive 或其他位置。

开启剪贴板自动收集后，应用会跳过混合文字、文件列表或带已知私密标记的内容，并避免重复导入应用自身的复制。此过滤不等同于识别所有敏感图片；可以始终保持关闭，仅使用主动 F3 贴图。

## 数据保存在何处

常规 Windows 安装的数据根目录为：

```text
%LOCALAPPDATA%\app.snapline.desktop\
├─ state.json     设置、图库索引和元数据
└─ library\      应用持有的媒体副本
```

路径由 Tauri 的应用本地数据目录决定。打包宿主、MSIX 文件系统重定向或用户目录设置可能使实际物理路径不同；**以设置页展示的资料库路径为准**，不要依赖示例中的固定用户名或盘符。免安装版也使用应用数据目录，不把图库默认保存在可执行文件旁。

索引包含文件名、路径、尺寸、时间、来源、收藏/收起状态及内容指纹等信息。媒体副本和设置没有应用层加密；能访问该 Windows 账户文件的程序可能读取它们。Windows 剪贴板历史、系统同步、外部备份或云盘软件各自的数据处理不由 Snapline 控制。

## 保留、删除与备份

导入不会移动或删除外部来源文件。图库删除和容量清理只针对应用资料库内的副本；从晾衣架“收起”只改变展示状态。

默认容量为 200 项。较早的未收藏项目会被清理；收藏、正在贴图或拖放的项目及刚加入的项目受到保护，可能暂时超过设定容量。收藏不是独立备份。

需要迁移或备份时，先退出应用，再复制实际数据目录中的 `state.json` 与完整 `library/`。只复制 `Snapline.exe` 不会迁移图库。清理数据前可先将要保留的图片导出；不要在应用运行中手工编辑索引。

标注保存为新的扁平 PNG，原图库图片仍然存在。遮盖后的图片不代表原图已删除，分享时请确认导出的是目标副本。

## 联网边界

应用界面与角色资源从本地构建产物加载，不从网络下载角色。仓库中的四套外部角色图由维护者提供，其来源与许可边界、移除后构建的行为见[角色素材说明](OPTIONAL-ASSETS.md)。

安装依赖、构建依赖以及缺少 WebView2 时安装运行时可能需要联网。WebView2 与 Windows 的更新、系统诊断和联网行为由其自身设置管理；“应用没有上传服务”不等于整个操作系统永不联网。用户主动在默认应用打开或拖出文件后，目标程序如何处理文件取决于该程序。

提交问题时请使用生成的示例图片，并移除真实截图、剪贴板内容、个人路径、索引和录屏中的隐私信息。详见[贡献指南](../CONTRIBUTING.md)。
