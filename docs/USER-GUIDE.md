# 使用指南

[返回项目首页](../README.md)

## 第一次使用

运行 Snapline 后，主窗口显示本地图库，屏幕顶部出现固定入口。桌面版不会预置示例照片。主窗口关闭后仍在托盘运行；托盘菜单提供打开主窗口、截图和退出。

默认快捷键为 F1 截图、F3 剪贴板贴图、Ctrl+Alt+T 展开或收起晾衣架。可在偏好设置中重新录入；Esc 取消录入。重复或被占用的组合会提示错误，原设置保留。与其他截图软件同时使用时请分配不同快捷键。

## 截图

按 F1 或点击“截取屏幕”，在冻结的桌面上拖出选区。拖动选区内部移动，拖动八个控制点调整大小；鼠标旁的“像素预览”是避让光标的小放大图，并非第二个鼠标。

“截图时隐藏晾图窗口”默认关闭。关闭时，设置窗口、灵动岛等当时可见的应用窗口会出现在冻结画面中；开启时临时隐藏，完成或取消后恢复。区域截图与全屏截图使用同一选项。

主窗口的“全屏截图”截取鼠标所在显示器并复制。区域截图的移动选区模式中，Ctrl+A 选择整个虚拟桌面，可能包含多台显示器。

| 截图操作 | 快捷键 |
| --- | --- |
| 复制当前选区与标注 | Enter / Ctrl+C；移动模式双击选区 |
| 把当前选区贴到屏幕 | Ctrl+T，或已成功注册的全局贴图键 |
| 另存为 | Ctrl+S |
| 回到移动选区 | V |
| 移动选区 | 方向键 1 个物理像素；Shift+方向键 10 像素 |
| 调整选区大小 | Ctrl+方向键 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z 或 Ctrl+Y |
| 隐藏 / 显示工具条 | 画布聚焦时按 Space |
| 调整粗细 | `[` / `]` |

工具条可选择矩形/椭圆、箭头/直线、画笔、荧光笔、文字、序号、马赛克/模糊/实色遮盖和橡皮。选中工具后展开相应参数；移动或改变选区边界时，标注仍保留在冻结桌面的原始像素位置，最终只输出选区内的部分。

截图画布中 R/O 为矩形/椭圆，A/L 为箭头/直线，B 或 P 为画笔，H 为荧光笔，T 为文字，N 为序号，M 为马赛克，E 为橡皮。Shift 可约束矩形/椭圆比例，或将线条吸附到 45° 方向。

文字工具点击后可输入多行文字，Enter 换行，Ctrl+Enter、右键或确认按钮完成；Esc 放弃当前文字。输入法组词时不会触发完成截图，未确认的文字须先完成或放弃。**T 是文字，Ctrl+T 才是贴图。**

Esc 按层级返回：先放弃当前文字或未完成笔画，再退出绘图工具，最后取消截图。右键有非空文字时确认文字，否则按相同层级返回。工具条取消按钮直接取消整张截图。按钮或下拉框聚焦时，Enter、Space、Esc 优先操作控件。

## 屏幕贴图

F3 读取剪贴板图片并创建置顶贴图，不需要开启自动剪贴板收集。也可以从图库贴图。截图完成后直接贴图会保留本次选区的桌面位置与像素尺寸；图库和剪贴板贴图使用默认布局。

| 贴图操作 | 方法 |
| --- | --- |
| 移动 | 按住图片拖动 |
| 缩放 | 滚轮或 `+` / `-` |
| 恢复原始大小 | `0` 或工具栏比例按钮 |
| 透明度 | Ctrl+滚轮、Ctrl `+` / `-`，或工具栏滑块，范围 15%–100% |
| 复制 | Ctrl+C 或菜单“复制” |
| 更多操作 | 右键、Shift+F10 或工具栏“更多操作” |
| 关闭 | Esc，或关闭按钮/菜单 |

右键是独立的 Windows 原生菜单，能超出小贴图边界。它提供另存为、再次标注、原始大小、缩略图、透明度和双击设置；菜单中的 Esc 先关闭菜单。

双击默认关闭，可改为“收起 / 展开”或“不执行操作”，设置会保存并同步至其他贴图。缩略图双击始终可恢复。关闭贴图不删除图库文件。

“再次标注”会关闭当前贴图并进入主窗口编辑器，保存为新副本；需要悬浮时可重新贴图。

## 顶部入口与晾衣架

入口左侧手柄只负责位置调整，悬停或短按不会展开。拖动后自动保存位置；聚焦手柄可用左右方向键微调，Shift 加快，Home 复位。只有中间宠物区域悬停或点击才展开晾衣架，右侧图标打开全屏图库。展开后紧凑入口隐藏，不占用整个屏幕顶边作为触发区。

晾衣架可显示图库中未收起的项目，使用滚轮、触控板或翻页按钮横向浏览。列表聚焦时可用左右方向键、PageUp/PageDown、Home/End 浏览。

- 单击图片复制；长按进入主窗口标注，双击用默认应用打开。
- 拖出向接受文件的应用提供副本；也可把支持的本地文件拖入。
- 悬停图片默认等待 1 秒打开临时大图，也可点击小眼睛立即查看。等待时间可设置为 1–5 秒，或关闭自动预览。
- 可点击图片的收起按钮，或按住图片左右晃动几次后松手，将它从晾衣架收起。晃动收起可关闭；普通拖出不会自动删除图片。
- 主窗口“晾衣架”页可以搜索正在晾晒/已收起的图片，逐项或批量收起、恢复。**收起只改变展示状态，不删除图库副本。**

绳子和照片在展开时轻微回弹；按住操作时暂停装饰运动。角色共 12 款，包括 8 款原创矢量角色和 4 套维护者提供的外部素材，可选 1–3 只混搭并关闭互动。素材来源与缺失时的行为见[角色素材说明](OPTIONAL-ASSETS.md)。应用遵循系统减少动态效果偏好，不主动修改系统设置。

## 大图与全屏图库

在快速预览或图库大图中，滚轮以鼠标位置为中心缩放；放大后可拖动平移，工具栏提供适应窗口和 100%。点击空白、右上角关闭或 Esc 退出当前图片；拖动结束不会被当作空白点击。

全屏图库提供搜索、收藏筛选和布局密度。点击图片进入大图，用左右按钮或方向键切换；大图可收藏、复制、导出或贴图。Esc 先返回图片墙，再退出全屏图库。视频仍从主窗口访问。

## 图库编辑与文件保留

图库编辑器在原始像素上绘制，提供形状、线条、画笔、荧光笔、文字、序号、马赛克、模糊、橡皮、实色遮盖与裁剪。Ctrl+S 保存扁平 PNG 新副本，不覆盖来源图。撤销/重做最多保留 100 步；关闭编辑器会丢弃未保存修改。

编辑器中的 B 是实色遮盖、P 是画笔、G 是模糊、C 是裁剪，与截图画布部分快捷键不同，以工具提示为准。已落笔对象不能事后单独选中移动。

橡皮恢复本次编辑的原始画面，可能擦掉本次新增的遮盖；无法还原已扁平保存的旧标注。需要彻底遮住内容时用实色遮盖，并检查最终输出。原图库项目仍然保留，分享前请确认选择的是处理后的副本。

导入、监视目录和拖入都会复制到应用资料库。删除图库项目或容量清理仅删除资料库副本，不删除外部来源文件。默认容量为 200 项，可在设置中调整；优先清理较早的未收藏项目，收藏、正在贴图/拖动的项目和刚加入项目受到保护，因此可能暂时超过上限。需要长期留存时请收藏或另行导出。

## 收集与排查

默认监视 Windows 截图目录和视频目录下的 Captures，实际目录显示在设置中。首次扫描仅记住已有文件，之后收集新增或变化的支持文件，不递归导入整个目录树。

自动收集剪贴板图片默认关闭。开启后只处理图片内容；混有文字/文件列表或已知私密标记的剪贴板会跳过，应用自身复制也不会重复导入。文件夹监视与主动 F3 贴图是独立功能。

如果快捷键无效，先查看设置中的注册提示；如果视频不能播放，可用默认应用打开，解码取决于 WebView2 与系统。数据位置、备份和联网边界见[隐私与数据](PRIVACY.md)；已验证硬件范围见[验证记录](VERIFICATION.md)。
