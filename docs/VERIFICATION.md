# 验证范围

本文区分历史实机观察、本轮自动检查和仍未覆盖的环境。测试计划见 [TEST-PLAN.md](TEST-PLAN.md)。记录不构成所有 Windows 设备或所有应用组合的兼容保证。

## 0.4.25 按钮焦点样式

本轮去除按钮焦点的底线、底部短标记和外框，改用控件内部底色提示。浏览器演示实际复现并对比了查看器关闭按钮的白色底弧，修复后已消失；通过 Tab 检查了已选中的“适应窗口”按钮，焦点底色仍可识别。输入框、截图选区边界和图片阴影保留。

本轮为 CSS 样式修正，没有重新执行下文 0.4.24 的全部测试，也没有重新验收原生截图、跨应用拖放和安装 / 卸载。

## 历史版本实际覆盖

下列是既往构建中的观察范围，**不是 0.4.24 的重新验收**：

- 两块实体显示器在 100% + 100% 扩展桌面下，执行过跨屏缝截图、另一屏原位贴图与贴图跨屏移动。几何模型还覆盖不同缩放和负坐标，但没有据此宣称对应硬件布局已通过。
- 使用真实鼠标与指定独立 OLE 接收程序，执行过文件拖出和两张 PNG 拖入，并核对文件内容。拖入发生在相关录像结束后，仅由独立日志与文件核验佐证。
- 实际截图启动录像的有限相邻帧检查中未观察到从中心扩大的效果；采样存在帧间间隙，不能排除未采到的瞬态，也不代表每次屏幕刷新均已检查。
- 原生窗口检查覆盖过明暗主题、800×600 主窗口、下拉避让、部分键盘焦点、顶部入口、晾衣架展开/滚动/收起、角色组合及重启保留。
- 截图显隐选项执行过默认关闭与开启的区域截图/取消：冻结画面分别保留或排除主窗与顶部入口。该批次没有完成全屏截图输出和持续按住 Esc 的实机验收。
- 最小 96×72 贴图执行过原生右键菜单、Esc 关闭菜单、Shift+F10 重开、原始大小、透明度与第二张贴图操作隔离。没有据此扩展为全部屏幕边缘和混合 DPI 菜单测试通过。
- 历史发行包执行过专用测试目录安装/卸载、可执行文件哈希检查及图库/设置差异检查。不同批次的数据基线独立记录，不将某一批次的结果套用到后续版本。
