# Windows 原生测试清单

这是测试计划，不是通过记录。实际结果写入 [VERIFICATION.md](VERIFICATION.md)，并注明版本、构建标识、Windows/WebView2、显示器布局与缩放。浏览器检查与原生操作分开记录。

## 发布前矩阵

| 范围 | 关键场景 | 核验重点 |
| --- | --- | --- |
| 安装与退出 | 新安装、升级、免安装、托盘退出、卸载 | 版本与产物一致；设置和图库按预期保留；无遗留窗口 |
| 截图启动 | 区域、鼠标所在屏幕全屏、取消、连续启动 | 解码就绪后显示；录制真实启动并逐帧检查，不以组件动画推断 |
| 截图显隐 | 默认关闭、开启、主窗最小化、图库仍加载、预览打开 | 关闭时冻结画面保留应用；开启时仅恢复本次隐藏的窗口；取消后焦点正确 |
| 截图标注 | 小选区、屏边、长文字、中文 IME、工具切换、撤销 | 选区与源像素一致；输入/菜单快捷键不误完成；输出包含最终标注 |
| 多屏 | 跨缝、原位贴图、移动到另一屏、布局变化 | 分开记录同 DPI、真实混合 DPI、负原点与 HDR；几何测试不冒充硬件结果 |
| 贴图 | 最小尺寸、屏边、缩放、透明度、收起/展开、双击 | 原生菜单不被图片裁切；菜单 Esc 不连关图片；两张贴图回调隔离 |
| 晾衣架 | 固定手柄、宠物区悬停、横向滚动、快速收起重开 | 不拦截整条顶边；按住时图片/绳冻结；释放与旧捕获事件安全 |
| 外部拖放 | 真实鼠标拖入多文件、拖出到接收应用、Esc、晃动收起 | 文件副本/哈希正确；来源保留；普通拖出不收起；退出后无拖影残留 |
| 图片查看 | 鼠标锚定缩放、拖动、适应/100%、长图、切换项目 | 拖后不误关；空白/X/Esc 正确；未激活悬停预览也能接受实际滚轮 |
| 数据与收集 | 导入、监视目录、剪贴板开关、容量清理、收藏、收起恢复 | 默认剪贴板关闭；仅清理库内非保护副本；不删除来源文件 |
| 设置与装饰 | 明暗主题、800×600、键盘导航、1–3 角色、减少动态 | 焦点可辨；无大外框；按住/隐藏暂停；设置重启后保留 |
| 素材兼容 | 四套本地素材存在、部分缺失、全部缺失 | 可用角色目录正确；仅内存回退，不因缺文件重写角色设置 |

## 自动检查

执行 [CONTRIBUTING.md](../CONTRIBUTING.md) 中的前端测试、类型/生产构建、Rust 测试、格式与 Clippy。Windows CI 成功证明构建和自动检查可执行，不证明真实多屏、IME、拖放或录屏场景已经通过。

## 结果记录

每个场景写明“通过 / 失败 / 未执行”和实际观察，失败修复后记录对应新构建。截图动画记录实际帧率、间隙与抽检范围；录像结束后的操作只能用单独证据说明，不标为录像覆盖。

使用可公开的合成素材。测试前记录资料库与设置基线，完成后比较文件和元数据，按实际差异报告；不要用旧状态覆盖用户新操作。测试时尊重已有系统设置，临时改动应在明确的测试范围内并恢复。公共文档不附个人路径、真实图片、私人索引或未经处理的录屏。
